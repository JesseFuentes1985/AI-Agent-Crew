🔒 Activity Gate Logic

Simple two-file system that prevents wasted work when Jesse isn't around.

memory/last-active.txt   ← updated at START of every session (Unix timestamp)
memory/last-save.txt     ← updated AFTER each successful session save

Check: last-active > last-save AND within 24h → SAVE
       last-active ≤ last-save               → SKIP (silent, zero cost)
ScenarioResult
Active today, not saved yetSaves
Already saved after last activitySkips
3 days offline3× Skips — zero cost
Come back after 3 daysSaves on first night back
