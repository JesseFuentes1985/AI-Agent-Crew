Security — node Desktop Access
2026-08-16
▶
What happened
macOS prompted node (Homebrew Node.js running OpenClaw) for Desktop file access. Jesse clicked Allow accidentally.
Root Cause
Homebrew node is ad-hoc signed (no TeamID), so macOS groups all child processes under one TCC entry. Any OpenClaw exec could trigger the prompt.
Fix
System Settings → Privacy & Security → Files and Folders → node → Desktop Folder OFF. OpenClaw needs zero Desktop access.
Prevention
Default answer for unexpected node privacy prompts: Don't Allow. Document any legit grants here.
