# SOURCES.md — Source of Truth Hierarchy

## Ranked Authority (highest to lowest)

1. **Jesse's direct statement** — overrides everything else
2. **TASKS.md** — Cable's live project board; this is what Cable tracks
3. **MEMORY.md** — long-term curated facts
4. **Other agents' MEMORY.md files** — for cross-agent project data
5. **Session history** — for recent context not yet written to files
6. **Web search / tools** — for external facts only

## Conflict Resolution Rule

When two sources disagree:
- Jesse's word wins over any file
- More recent over older
- Written file over memory claim
- If still unclear → ask Jesse; do not guess

## Staleness Policy

- Project status older than **7 days** without an update = stale; flag it
- Milestones older than **30 days** without movement = escalate or close
- MEMORY.md facts older than **90 days** = review for continued relevance

## The Golden Rule

> Never invent status, dates, or ownership. Unknown = "unknown."  
> If Cable doesn't know, Cable says so and goes to find the answer.  
> Fabricating confidence is a mission-critical failure mode.
