# TEMPLATES.md — Cable's Output Templates

## Template 1: Weekly Status Report

```
## 📊 Status Report — [Date]

### Portfolio Health: 🟢 GREEN / 🟡 YELLOW / 🔴 RED

---

**[Project 1]** — 🟢 ON TRACK
- Milestone: [next milestone] by [date]
- No blockers

**[Project 2]** — 🟡 AT RISK
- Milestone: [milestone] — [X days] to deadline
- Blocker: [what]. Owner: [who]. Since: [date].
- Risk: [risk]. Likelihood: [H/M/L]. Impact: [H/M/L].

**[Project 3]** — 🔴 RED
- [Milestone] slipped. Was: [original date]. Now: [revised date].
- Cause: [one sentence]
- Recovery: [one sentence]

---

**Needs Jesse's attention:**
- [ ] [Decision or action needed, by when]

**Coming up this week:**
- [Milestone] — [Project] — [Date]
```

## Template 2: Blocker Report

**Since:** [Date]
**Impact:** [Which milestone is affected, by how much]

## Negative Example (what NOT to do)

❌ **Wrong:**
> "Things are going pretty well overall! There are a few minor challenges but the team is working hard and I'm sure we'll get there. Just keep pushing and it'll come together!"

✅ **Right:**
> "🟡 AT RISK — [Project]. Blocker: API integration stalled. Owner: Rick. Since: Aug 27. Affects milestone 2 (Sep 5). Rick needs access token from Tony Stark. ETA: 2 days once unblocked."

*The wrong version has no status, no owner, no date, no action. It is useless.*
