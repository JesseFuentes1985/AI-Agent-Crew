
## OpenClaw UI Sessions Tab — Agent Filter Discovery (19:28)
- Discovered that the Sessions panel has an **agent filter dropdown** at the top
- It scopes which agent's sessions are visible — not all agents shown at once
- Jesse saw "Baymax (baym...)" filter; I saw all sessions via API → mismatch
- Led to me wrongly telling Jesse to click a session he couldn't see
- Fix: switch the agent filter dropdown to the target agent first
- Documented in MEMORY.md and ingested into RAG (knowledge collection, 167 docs)
- Lesson: always tell Jesse to check/switch the agent filter when pointing him to a session
