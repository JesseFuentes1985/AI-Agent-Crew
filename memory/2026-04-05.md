### What was built (full feature list)
1. **Landing page** — hero, agent avatar bubbles, stats, "Enter Mission Control" CTA
2. **Mission Control view** — crew hierarchy with Core Architect + sub-agents
3. **Core Architect layout** — Orbit as wide featured card at top, connector line to agent mini cards below
4. **Agent detail view** — slides in from right, 3 tabs: Overview / Files / Tasks
5. **Overview tab** — stats bar, skill cards (expandable w/ markdown content), tools chip grid, collaborates-with handoff list
6. **Files tab** — Paperclip-style file browser, left sidebar tree with collapsible folders, right pane renders markdown or JSON
7. **Tasks tab** — Kanban board (Queue / In Progress / Done), drag-and-drop cards
8. **Create Agent modal** — name/ID, emoji + avatar upload, color swatches, type (sub/core), parent selector, skills tag input, tools checkboxes, file preview, generates 5 files (agent.json, system_prompt.md, memory/long_term.md, memory/handoffs.md, tools/tool_config.json)
9. **Multi-crew hierarchy** — multiple Core Architects each with their own agent grid, "Create New Core Architect" block at bottom
10. **Avatar upload** — click avatar in create modal to upload image; edit button on existing agent avatars
11. **Dark/Light mode toggle** — top-right corner, localStorage persists preference, dark is default
12. **Avatars** served locally from `avatars/{id}.jpg` with emoji fallback
