## Session: Memory System Design

### What Jesse Asked
Jesse asked how Orbit's memory actually works — specifically: if he restarts, will Orbit still know the mission? He also asked about using Ollama to build a memory system that grows smarter over time.

### What We Built
**`tools/session_saver.py`** — full pipeline to save sessions into mem0:
- Pulls session history JSON (from OpenClaw `sessions_history` tool)
- Sends transcript to `nous-hermes2` (Ollama, local) for summary + fact extraction
- Stores extracted facts in Qdrant via mem0 with semantic embeddings (nomic-embed-text, 768-dim)
- Saves full transcript to `memory/sessions/YYYY-MM-DD-label.md`
- Recall: `python3 tools/session_saver.py --recall "query" --agent orbit`

**`tools/save_session.sh`** — shell wrapper for the above

### First Session Saved

### How Ollama Grows With Us
mem0 uses `nomic-embed-text` to create 768-dim semantic vectors. Every session adds vectors. Searches find semantically similar context across ALL past sessions — not keyword matching. The more sessions saved, the smarter recall gets. This is the "grows with you" behavior Jesse wanted.
