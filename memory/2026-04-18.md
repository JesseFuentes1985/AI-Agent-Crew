### Problem: "openclaw doctor" memory search warning kept appearing
- Warning: "Memory search provider is set to 'ollama' but the API key was not found in the CLI environment"
- Root cause: `OLLAMA_API_KEY` not set in shell/LaunchAgent environment
- The gateway itself was fine — embeddings ready, memory indexed — this was a CLI env false positive

### Problem: New sessions being spawned (Jesse seeing "new rooms")
- Main session was hitting context overflow with 131–133 messages
- Compaction was failing 3x then spawning a new session ID to recover
- Root cause: AGENTS.md + SOUL.md + MEMORY.md + all project context injected every turn = massive token load

- ✅ **35 orphan transcript files** archived (ghost sessions from overflow restarts)
- ✅ Gateway restarted — came back clean, doctor ran with no warnings
- ✅ Memory search warning resolved — doctor shows clean
